# Khlang

A responsive Next.js and React coming-soon page.

## Development

Install dependencies with `bun install`, then run `bun run dev`.
Open http://localhost:3000.

## Checks and production

- `bun run typecheck` checks TypeScript.
- `bun run build` creates the production build.
- `bun run start` serves the production build.

Edit `app/page.tsx` to change the text and `app/globals.css` to change the styling.
